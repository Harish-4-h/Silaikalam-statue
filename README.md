# SILAIKALAM STATUE MAKERS — Official Business Website
**Custom Statue & Sculpture Manufacturers • Kalaiyanur, Coimbatore, Tamil Nadu**

---

## 🏛️ About This Website
This is the production-ready official business website built for **Silaikalam Statue Makers**, handcrafted sculpture manufacturers based in Kalaiyanur on the Anaikatti / Thadagam Road in Coimbatore, Tamil Nadu with **14+ years of craftsmanship experience**.

The website is designed with a premium artisanal visual identity (deep charcoal, warm ivory, antique gold, and stone textures) that emphasizes physical manufacturing and craftsmanship.

---

## 🛠️ Tech Stack
- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS with custom sculpture aesthetic palette
- **Icons:** Lucide React
- **SEO & Schema:** Full OpenGraph, Twitter Cards & JSON-LD `LocalBusiness` structured data
- **Mobile Experience:** Sticky conversion action bar (Call, WhatsApp, Get Quote) + responsive touch controls

## 🚀 Running Locally
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

---

## 📦 Deploying to Production
You can deploy this site in one step to **Vercel**, **Netlify**, or **Cloudflare Pages**:
1. Run `npm run build` to generate the static files in `dist/`.
2. Upload the `dist/` folder or connect the Git repository to Vercel/Netlify.
3. Configure your custom domain (e.g., `silaikalam.com`).
